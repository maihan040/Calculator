Basic iPhone-Style Calculator
A simple calculator web app inspired by the look and feel of the iPhone calculator. Built with modern HTML, CSS, and (extendable) JavaScript, it features large, touch-friendly buttons and visually authentic styling.

Features
iPhone-style, responsive calculator UI

Supports basic arithmetic operations, percentages, negation, and clear

Built with semantic, modular HTML and maintainable CSS

Easily extendable for additional functionality

Installation
Clone this repository: https://github.com/maihan040/Calculator

Usage
Click or tap the number and operator buttons to perform calculations.

Use:

AC to clear all input

+/- to toggle the sign

% for percent operations

. for decimal numbers

= for results
